# LI 网站拦截器 · 开发历程与思路总结（v1.0.2）

> 记录于 2026-08-24

## 一、项目概述
一个面向 Chrome / Edge 的 Manifest V3 浏览器扩展：拦截指定网站，帮助专注与自律。
技术栈：WXT + TypeScript + Vite、`chrome.storage.local`、WebCrypto（PBKDF2 / AES-GCM）、Vitest 单测。

## 二、功能演进
1. **v1 MVP**：全屏拦截页、快速添加（弹窗 / 右键）、白名单、随机密码（仅展示一次）、倒计时解锁 + 固定允许时段、衍生网站扩展、JSON 导出导入。
2. **v2 全量对齐参考扩展（Extfy Website Blocker）**：匹配模式（域名 / 包含 / 精确 / 通配 / 全URL）× 拦截类型（永久 / 计时 / 按次 / 排程）、白名单模式 + 全站白名单、关键词拦截、静默拦截、禁用冷却、多档案 Profiles、番茄钟、历史记录、深色模式、图标角标倒计时、v1→v2 数据迁移。
3. **增强**：OmniBox 命令（`bl add/allow/on/off/list`）、键盘快捷键、规则去重、今日统计面板、预置模板、列表搜索过滤。
4. **i18n 多语言**：内置中 / 英词典，随浏览器语言或手动切换；主题支持「跟随系统」。
5. **同步**：WebDAV（PUT/GET + Basic）、S3 / S3 兼容（AWS Signature V4），同步配置 AES-GCM 加密存储。
6. **体验**：批量添加域名、临时暂停（防打扰）、首次安装引导页、卡通手绘 UI 与品牌（盾牌 Logo + 图标）。

## 三、关键设计决策
- **默认只拦当前域名**：衍生扩展（子域 / TLD 变体 / 镜像）默认不勾选；迁移 v3 将旧规则收窄为精确域名。
- **判定优先级**：白名单 > 全站白名单模式 > 关键词 > 拦截规则（按类型）> 放行；会话放行 / 倒计时按去 `www` 的规范化域名匹配。
- **显式拦截立即生效**：弹窗 / 右键 / OmniBox 的「拦截本站」无视全局开关与暂停，立刻重定向当前页。
- **角标倒计时仅在被拦截网页显示**：按当前活动标签页判定，临时放行或其它页面不显示。
- **只拦截+去重**：同文本同模式自动合并。

## 四、主要修复的 Bug
- 弹窗拦截后需手动刷新 → 改为自动重定向。
- 临时访问后 `www` 域名不匹配 → 统一按规范化域名匹配。
- 删除规则后重新添加被旧会话放行覆盖 → 添加/删除时清空该域名放行与倒计时。
- `__MSG_*` 不替换（显示裸文本）→ 内置中英词典兜底 + 运行时二次替换。
- 图标白底 / 图标消失 → SVG 去除固有尺寸重新渲染为透明高对比盾牌。
- `javascript:` 链接触发 CSP 报错 → 改为 `#` + preventDefault。
- WXT 类型生成因消息值含 `*/` 或引号失败 → 清理消息文案。
